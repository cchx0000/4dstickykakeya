# Global point degree does not supply arbitrary parent-scale accuracy

Source audit, 2026-10-06. This records a rejected transfer, not a new
assumption or a contradiction to the original theorem.

The genuine global point-degree reader on a fixed Reference controls each
literal original point fiber by delta^(-kappa-tau), after its prescribed
cost and cutoff payments. The target of a later parent-normalized counting
argument may instead require (delta/Rho)^(-kappa-etaDegree).

The current NativeRankMesoscopicRadiusMenu.menu permits scheduled depth
up to level/4. Its actual radius_ge_quarter_power lower bound is

    rStop >= delta^(1/4)/48.

Combined with the actual squared-parent guard3072*rStop<=Rho^2, this gives

    Rho >= 8*delta^(1/8).

The exponent1/8 is fixed. It does not become small when the later rank
parameter c is reduced. In particular, the rank stop's separate upper
bound rStop<=delta^(cutoff c ell) cannot be substituted for this lower
bound.

At the limiting permitted scale Rho proportional to delta^(1/8), the
proposed degree comparison requires

    (7/8)*(kappa+etaDegree) >= kappa+tau,
    etaDegree >= kappa/7 + 8*tau/7.

Fixed numeric factors may be absorbed by a cutoff, but this positive
power loss cannot. Thus this route cannot yield every arbitrarily small
output tolerance when kappa>0. No small-c replacement window has been
derived from the current producer.

The viable remaining interface is to use the actual conditional
parent-point relation and its stored parent multiplicity bound, on the
same reference and same retained incidence set. If a later coordinate or
mesh map merges original points, its true inverse-image capacity must
also be proved. Neither the global reader nor a redefinition of delta as
the new parent thickness supplies that capacity. Alternatively, a caller
that genuinely stays on literal Reference.E1 may use the global bound
there, without pretending it has been rescaled.

The separate original-incidence height normalization and its checked
raw total-mass lower do not rely on this rejected global-degree transfer.
Equation(143) remains unclosed until its actual consuming graph and all
conditional point/label counts are connected at the same scale.
