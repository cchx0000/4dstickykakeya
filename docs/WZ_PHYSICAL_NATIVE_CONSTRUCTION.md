# Original-source parent and physical-W construction

This checkpoint adds fourteen Lean modules and 140 proved declarations.
It connects the previously checked finite combinatorics to literal original
source cells, original incidences, actual mesh heights and physical directions.
It does not complete the final volume theorem.

## Native parent and quantized patch construction

`NativeParentSpines` assigns original rich spines to actual original parent
cells before angular refinement. It constructs the simultaneous spatial,
spatial/angular and source-fiber/spatial uniformities, and derives the required
parent masses and fiber-parent menu bounds from the same stopped tube profile.

`NativeContactSpineColumns` keeps the genuine thin-spine width in its counting
capacity. A point in a retained whole child cell need not lie on the thin
spine; instead its contact point is constructed in that child, and the added
child-width error is included in the physical overlap calculation.
`NativeContactFractionalComposition` then supplies the six references to the
same-parent fractional refinement.

`NativeAngularChartSelection` selects one of the two actual coordinate charts,
transports the original AD and tube-profile data exactly, and constructs
nested finite slope labels, their menu bounds and the retained angular level.
`NativeSeparatedFractionalPatches` selects an actual source residue before
fractional refinement, supplies physical quantization proximity, and isolates
parent patches. It does not assert that a many-to-one quantized image inherits
the original AD lower bound.

`RealScaleTubeProfileTransfer` constructs the finite grid comparisons and
ordered dyadic brackets needed to transfer the stopped profile to arbitrary
eligible real query widths and lengths, including shifted normalized grids.
The remaining literal normalized-fiber and final near-alignment assembly is
separate work.

## Original-W physical growth

Seven modules construct the actual original-point core and deterministic
successors, preserve the original height at every step, derive fine-to-coarse
slab constants, and derive displacement from the original two incidences.
The fixed representative lies on the same original tube at the same original
height. No representative-motion estimate is assumed.

The scalar and planar native endpoints now combine those data with the
checked transverse-menu argument. The height normalization is also derived
from the original mesh: an interval of length rho squared contains at most
`3 rho^2 / delta` original height labels when `delta <= rho^2`. The retained
height density consequently supplies the actual `lambda / (3 rho)` ratio.
See [the exact physical interface](WZ_ORIGINAL_W_NATIVE_GROWTH_INTERFACE.md).

The subsequent original-tube ancestor counting and actual convex-box volume
are not included in this checkpoint. In particular, occupied parameter-cell
lower populations require the original dyadic carrier AD hypothesis; a
carrier-ball bound is not silently substituted for it. The global normalized
CW division also needs the original bounded parameter support or its global
cardinality consequence.
