## What is constructed

`DisjointProfileEpochs` constructs the finite process that alternates whole
low-population cell deletion with genuine nonempty extraction. Its occupied
cell penalty telescopes through both actions, so every cell is charged only
once globally. A second recursion freezes a selected monotone integer profile
per epoch and bounds the number of epochs by the actual finite profile rank.
It returns disjoint ORIGINAL-point fibers in one fixed-source epoch with a
proved total retention bound. No retained family is given as an input.
The geometric scale-selection rule is still a separate caller. Natural floors
of real thresholds avoid an additive ceiling cost; regular nonempty cells
meet half the intended real threshold and the total penalty stays within the
original real budget.

`WholeGridCellExtraction` supplies the literal integer-grid adapter, including
negative coordinates. Extracting every current point in a fine cell meeting
an actual witness set preserves EXACTLY its image at every coarser divisible
grid scale. Removed cells stay empty in the residual. The original witness
lies within one fine mesh in every coordinate.

`SmallFiberAlignment` constructs a heaviest-vertex choice in each normal
column and a single final refinement, yielding singleton fibers and actual
quotient count bounds with the stated H N^s loss.
`FractionalFiberAlignment` handles general fractional s. One refinement of
the actual spatial, column/time and column partitions constructs a single
original-label subset with spatial, fiber and quotient count bounds. The
quotient upper bound sums WHOLE final fibers inside the full reference strip.
Original weights, vertex capacities and genuine column/strip menus are
explicit inputs; a final AD or alignment certificate is not.

`SpineColumnCounting.physical_spines_column_count` derives the missing column
overlap estimate from original physical spines and actual anchors. It uses
contact residual, slope difference, time length and seed error to compare
two real witnesses in the same original floor cell. This derives the integer
box bound on how many normal labels can meet that cell, and then the column
count by double counting. Neither overlap nor the column-count conclusion
is an input. The rich spine-cell count is the remaining preceding caller at
this interface.

`SeparatedAlignmentPatches` constructs maximum-weight periodic colors on
actual parent cells and proves the literal local-ball identity for every
retained original label. It also constructs shear quantization plus residue
selection, proving original-mass retention, separation and BOTH near-image
directions. This checkpoint's metric endpoint uses the sup metric on finite
coordinate products; Euclidean conversion is separate.
